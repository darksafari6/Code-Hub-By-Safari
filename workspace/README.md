# Workspace

This folder is the project Safari AI Dev Studio edits, previews and runs
commands in. Everything here is yours — create, rename and delete files freely
from the Explorer.

- `index.html` is the default preview target (`/preview/`).
- The integrated terminal starts in this directory.
- Source Control initialises a git repository here.

Change the folder with the `WORKSPACE_DIR` environment variable if you want the
IDE to work on a different project.
